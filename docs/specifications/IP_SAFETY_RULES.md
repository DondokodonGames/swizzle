# 権利ルール（IP Safety Rules）— 量産前に固定する canon

**原則: ジャンルとメカニクスは自由。固有名詞・キャラクター・特徴的なビジュアルは完全オリジナル。**

800本規模で自動量産するほど、寄りすぎたものが混ざる確率が上がる。1本ずつ作るなら気づくことが、
量産では見逃される。だからルールをテンプレートに固定し、機械チェックを関門に置く。

- 機械チェック: `src/ai/code/IpSafetyChecker.ts`（`CodeGameValidator` から常時実行）
- 一括スキャン: `npm run games:ip`（`--all` で warning と許諾済みIPも表示）
- 検出できないもの（人間が見る）: 名前を出さずビジュアルだけ寄せたケース、特定タイトルの画面構成の再現

---

## 1. 借りてよいもの / いけないもの

| 借りてよい | 借りてはいけない |
|---|---|
| ジャンル（マイクロゲーム集、ボードパーティ、リズム、落ち物、固定砲台STG…） | タイトル名・シリーズ名 |
| メカニクス（同種合体、連鎖、回避、タイミング一発…） | キャラクター名・キャラクターの見た目 |
| 題材（ゾンビ、地球防衛、電車、廃墟、脱出部屋…） | 独特のUIデザイン・画面構成の再現 |
| 様式（ドット絵、CRTスキャンライン、チップチューン、8bit配色） | ロゴ・書体・効果音の複製 |

**「〇〇風」で作らせない。** Codex/LLM に「〇〇風」と指示すると寄りすぎる。
指示は必ず「**このメカニクスで、完全オリジナルの見た目で**」の形にする。
公開名（タイトル・説明文）に「〇〇風」を使わない。

## 2. ジャンル階層ごとの扱い

| 階層 | 例 | 権利リスク | 指示の書き方 |
|---|---|---|---|
| 安全 | ハイパーカジュアル / 動画広告ゲーム / TikTok系 | 低（特定権利者のいないメカニクスの集合） | メカニクス名で指示 |
| 安全 | ジェネリックファミコン | 低（ドット様式は権利ではない） | 「8bitドット様式」で指示。ハード名は公開名に出さない |
| 注意 | Simple2000題材 | 中 | 題材（地球防衛・ゾンビ・電車）は可。**ブランド名・D3商標は不可**。シリーズ名そのもの（例: 地球防衛軍）も避け独自の部隊名にする |
| 注意 | ゲーム実況で見る景色の再現 | 中 | ジャンルの典型風景（ホラー廃墟・脱出部屋）は可。**特定タイトルの画面再現は複製** |
| **特に危険** | メイドインワリオ風 / マリオパーティ風 / リズム天国風 | 高（すべて任天堂IP） | ジャンル（マイクロゲーム集／ボードパーティ／リズム）は借りてよい。**名前・キャラ・独特のUIを寄せない。「〇〇風」の名前で公開しない** |

## 3. 許諾済みIP（例外）

**CAPCOM（許諾済み）/ SNK（NDA下で許諾済み）** は、②ジェネリックアーケード枠でこれらのIPに寄せてよい。
チェッカーは違反にせず `licensedHits` として記録する（枠の取り違えを検出するため）。
それ以外の権利者（任天堂・セガ・コナミ・バンダイナムコ・タイトー・スクエニ等）は許諾がないので寄せない。

## 4. 生成テンプレートに固定する文言

新規生成・書き換えのどちらのプロンプトにも、この段落をそのまま入れる。

```
## 権利ルール（違反は無条件でやり直し）
- ジャンルとメカニクスは自由に借りてよい。固有名詞・キャラクター・独特のUIは完全オリジナルにする
- 実在タイトル名・キャラクター名・権利者名をコード内（コメント・世界観・描画文字列・ファイル名）に書かない
- 「〇〇風」という表現で作らない／名付けない。作るのは「このメカニクスの、完全オリジナルの見た目」
- 様式（ドット絵・CRT・チップチューン）と題材（ゾンビ・電車・廃墟）は借りてよい
- 例外: CAPCOM / SNK は許諾済み。ただし指示に明記がある場合のみ
```

## 5. 検出の運用

| タイミング | 何をする |
|---|---|
| 生成直後 | `CodeGameValidator.validate()` が IP_RISK を error として返す → 再生成 |
| バッチ書き換え時 | コミット前に `npm run games:ip` |
| アップロード前 | `run-upload-examples` の validation で弾かれる |
| 定期 | 語彙リストの見直し（新しく流行したタイトルを追加する） |

`IP_DENY_LIST` に語を足すときの基準:
- **明白な固有名詞だけ**を入れる。一般語と衝突する短い語（リンク／ピーチ／スイッチ／イカ）は入れない
- 一般語と同形になりうる語は `except` で打ち消すか、英題のみで検出する（例: 鉄拳／バイオハザード）
- 誤検出は「作れるはずのものが作れない」損失を生むので、迷ったら warning に落とす
